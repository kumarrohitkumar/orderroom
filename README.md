# OrderRoom

An FMCG distributor's order desk inside the team chat. Salesmen order in Hinglish on Telegram, the manager and godown work in Mattermost, and one AI agent placed by [Switch](https://github.com/sandbox-quantum/switch) checks stock and credit, routes approvals, bills, and tracks dispatch. Rules are enforced in code, not in the prompt.

Built solo for the WeMakeDevs × DevTools Academy **Flip the Switch** hackathon (Nov 4–7, 2026), Track 01: Best Business Workflow.

> Work in progress. Design docs: [PLAN.md](PLAN.md), [docs/HLD.md](docs/HLD.md), [docs/LLD.md](docs/LLD.md), [docs/DECISIONS.md](docs/DECISIONS.md).

All data is made up. No real companies, customers or brands.
